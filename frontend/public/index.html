FEATURES

为刷题体验而生

三大支柱构成 MiniOJ：强一致的评测、强隔离的资源、强可控的运维。

秒级评测

fork + exec + setrlimit 子进程隔离，统一 AC / WA / TLE / MLE / RE / CE 六态判定，500 ms 单用例上限不让恶意代码拖垮机器。

资源受限

CPU、地址空间、文件大小、输出字节全部走 setrlimit 严格封顶；并发提交通过信号量排队，FIFO 调度，避免雪崩。

开箱即用

docker compose up -d 一键拉起 MySQL + 后端 + Nginx；管理员账号密码 seed 脚本生成，配置文件即环境变量。

HOW IT WORKS

三步完成一次评测

从打开题目到看到 AC，全流程不超过 2 秒。

  1. 01

    选题目

    题单支持按难度和标签筛选，进入题目详情查看 Markdown 描述与样例输入输出。

    /problems.html
  2. 02

    写代码

    内置编辑器（CodeMirror 6）支持语法高亮、自动缩进与一键模板加载，C++17 标准库全开。

    /problem.html?id=1
  3. 03

    提交评测

    提交后 Worker 池调度编译子进程，遍历用例并汇总 verdict，结果按用例粒度返回。

    POST /api/submissions
